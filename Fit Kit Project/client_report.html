Client / Developer Team Project Report

Client Report

How did you decide what content and images to use for your site plan?

The content and images were chosen based on the purpose of the website, which is to help users understand body types and fitness plans. The images were selected to visually represent fitness, workouts, and body types in a simple and clear way. The text content was written to be beginner-friendly so that users with little or no fitness experience can easily understand the information.

How did you communicate with your developer? Was there any issues with communication?

Communication was done through direct discussions where feedback and updates were shared. The developer asked questions when clarification was needed, and updates were provided throughout the project. There were minimal communication issues, and most questions were resolved quickly.

Did your developer meet your expectations for your site?

Yes, the developer met expectations by properly structuring the website, applying styling with CSS, and organizing the layout according to the site plan. The design is clean, functional, and visually appealing.

What will you do differently next time you hire a developer to do a project for you?

Next time, I would provide more detailed requirements and examples at the beginning of the project. I would also maintain more frequent communication and request progress updates more often to ensure everything is aligned with expectations.

Lead Developer Report

How did you communicate with your client? Was there any issues?

Communication with the client was done through regular updates and feedback requests. The client was responsive and provided clear input, which helped guide the design and development process. There were no major communication issues.

How did you handle publishing your clients site and sharing it with the client?

The site was published using GitHub Pages. After uploading all project files to the repository, GitHub Pages was enabled to host the website. The live link was then shared with the client for review and feedback.

How was your experience with managing your site with GitHub?

Managing the site with GitHub was organized and efficient. It allowed for version control, easy updates, and reliable hosting through GitHub Pages. Uploading changes and tracking updates made the workflow structured and manageable.

General Experience and Reflections

What was the most challenging part of this project for you? Were you able to overcome it?

The most challenging part of this project was organizing the layout and ensuring that all pages were properly linked together. Understanding how to structure multiple pages and apply consistent styling across them required careful attention. This challenge was overcome by reviewing the HTML structure, testing navigation links, and making adjustments as needed.

What did you enjoy most about this project?

The most enjoyable part of the project was seeing the website come together visually after applying CSS styling. It was rewarding to turn a basic HTML structure into a more professional and visually appealing website.

What would you do differently if you could do the project again?

If I could redo the project, I would plan the layout and structure in more detail before starting development. I would also create all pages earlier in the process and test navigation links sooner to avoid rework.

Do you feel more confident in working on real-world projects after this experience? Explain.

Yes, this project increased my confidence in working on real-world web development tasks. It helped me understand how to collaborate with a client, manage a project, use GitHub for hosting, and build a complete multi-page website. I now feel more comfortable handling similar projects in the future.
